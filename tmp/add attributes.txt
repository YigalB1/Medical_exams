For each question in each exam, few attributes will be presented on top of the page for the user.
The user will be able to select none, one or more attributes for each question.
Attributes that are not selected will remain gray.
Selected attributes will be colored with yellow.
These selected attributes will be registered (where?).
Next time the question will be presented, the selected attributes will be yellowed again.

Later on, when user is selecting an exam by specialty (such as Lungs), the user will be able to either:
1- Select fulll exam as now
2- Select only questions with specific attribute(s)
